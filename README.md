🏡 Moflis - 스마트 운동 매칭 서비스

“채팅, 일정 관리, 위치 인증까지! Moflis에서 한 번에 해결하세요.”

🔥 Moflis란?

Moflis는 사용자의 일정과 매칭을 자동으로 관리해주는 혁신적인 서비스입니다.
채팅, 위치 인증, 캘린더 일정 자동 관리, 매칭 추천 등의 기능을 제공합니다.

❓ Moflis는 어떤 문제를 해결할까요?

사용자 일정 관리가 불편한가요? → 자동화된 캘린더 기능

위치 인증이 필요한가요? → 실시간 위치 인증 지원

최적의 매칭이 필요하신가요? → 관심사 및 위치 기반 추천 시스템

🚀 주요 기능

✅ 실시간 채팅 - 1:1 및 그룹 채팅, 파일 전송, 알림 기능
✅ 위치 인증 - 신뢰할 수 있는 위치 확인 기능
✅ 캘린더 자동 관리 - 일정 자동 등록 및 알림 지원

🛠 기술 스택

백엔드: Spring Boot, JPA, Redis, WebSocket

데이터베이스: MySQL

프론트엔드: React, Tailwind CSS

배포: AWS (EC2, S3, RDS)

⚡ 기술적 이슈 & 해결 과정

1️⃣ 대량 트래픽 문제 해결 - 세션 클러스터링 적용
2️⃣ 위치 인증 보안 강화 - Validation 및 암호화 적용
