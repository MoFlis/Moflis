# Moflis - 운동 매칭 서비스

평소 사용하던 운동 매칭 관련 앱을 이용하면서, 같은 지역에서 동일한 운동을 하는 사람과 효율적으로 매칭되기 어렵다는 문제를 느꼈습니다. 이를 해결하기 위해, 사용자의 위치, 운동 종목, 운동 시간대 등의 기준을 설정하여 정확한 매칭을 제공하는 시스템을 개발했습니다.

# 주요 기능

- 위치 인증 - 사용자가 등록한 주소와 실제 위치를 인증하는 기능을 추가하여 매칭의 신뢰도를 높였습니다. 이를 통해 위치 정보를 악용한 부정확한 매칭을 방지했습니다.
- 캘린더 기반 스케줄 관리 - 사용자가 생성한 운동 스케줄을 캘린더에 저장하고, 그룹 일정과 개인 일정을 통합 관리할 수 있도록 설계했습니다. 또한, 그룹 일정과 개인 캘린더를 자동 동기화하는 기능을 개발하여, 사용자가 그룹에 참여하면 해당 일정이 자동 추가되도록 구현했습니다.
- 리뷰 및 평점 - 같이 운동 했던 파트너에 대한 리뷰를 작성하고 평점 부여를 할 수 있는 기능을 개발 했습니다.
- 매칭 추천 시스템 - 사용자의 위치, 선호 운동, 프로필 정보를 분석하여 매칭을 추천하는 시스템 개발사용자가 빠르고 편리하게 자신의 레벨에 맞는 사람들의 매칭을 글을 볼 수 있게 추천 글을 보여주는 기능을 개발했습니다.
- 채팅 기능 - 매칭을 원하는 사람들끼리 원활한 소통을 위해 채팅 기능을 개발 했습니다.

# 기술 스택

- 백엔드: Spring Boot, JPA, Websocket
- 데이터베이스: MySQL
